100% static · no database

Shortlink

The whole destination is packed into the link itself — nothing is stored anywhere.

API

Returns the short link as plain text — the body is the link and nothing else. Failures are one error: … line.

GET /s/api/gen/#<url>
       ?emoji=1   allow the emoji alphabet

The url rides in the fragment, so it never reaches a server.

From a terminal

This site is static, so nothing computes a link server-side and curl alone cannot drive the endpoint above. Fetch the codecs and run them locally instead:

curl -s https://austin-code.com/s/cli.js \
  | node - "https://example.com/long/url"

  --emoji            allow the emoji alphabet
  --decode <code>    the other direction
  --base <url>       another deployment

cli.js pulls codecs.js and runs the same four codecs this page does, so it always agrees with the site.
